# ADR - 002 Adotar Framework Nexts.js

## Status

accepted

## Context

Construção de um MVP em menos de uma semana. Além disso, alguns membros da equipe possuem experiência com React que é responsável por gerar as interfaces no Next.js.

## Decision

Arquitetura monolítica

## Consequences

### Vantagens
- Simplicidade no desenvolvimento
- Cumprimento dos prazos

### Desvantagens
- Maior curva de aprendizado e dificuldade para os desenvolvedores não familiarizados com a tecnologia.
- Risco de criar acoplamento no framework
