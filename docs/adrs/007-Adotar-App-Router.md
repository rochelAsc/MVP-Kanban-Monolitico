# ADR - 007: Adoção do App Router do Next.js

## Status

Aceito

## Contexto

O Next.js oferece diferentes formas de organização de rotas. A abordagem mais recente é o App Router, baseado na pasta app, que permite organizar páginas, layouts e rotas de forma integrada. Como o projeto foi iniciado em uma versão recente do Next.js, foi escolhida a abordagem atual recomendada pelo framework.

## Decisão

Adotar o App Router do Next.js como mecanismo de organização de rotas e páginas.

## Consequências

- Uso do padrão atual do Next.js
- Organização das páginas por estrutura de arquivos e diretórios
- Facilidade para uso de recursos como layouts, Server Components e Server Actions
- Boa integração com o restante da arquitetura escolhida
- Necessidade de conhecimento específico sobre o funcionamento do App Router
- Maior dependência dos padrões definidos pelo Next.js
